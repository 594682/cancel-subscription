# 订阅 / Subscription — 空气 PRO v2.2.0

**Minecraft Java 1.21.1 / NeoForge 21.1.x / Java 21**

这是一款恶搞订阅游戏模组，全部收费都是 Minecraft **绿宝石**，不涉及真钱。

## 游玩方法

- 按 **O** 打开 **999 GOLD 空气 PRO** 订阅中心。
- 开通会员需要 10 个绿宝石。会员可能因听到音效、周围方块更新等产生额外账单。
- 空气 PRO 每隔约 **30～90 秒**，会向背包**空槽**随机发放 1～3 个不存在的物品（竖半砖、横梯子、水半砖、冰台阶、空气玻璃、虚空方块）；右键方块尝试放置它们时，只消耗物品，不生成方块。
- 退款流程仍然有 **10 道挽留关卡**。退款后停止其他事件扣费和物品补货，**保留玩家在线时每 5 秒扣 10 颗绿宝石**。
- **维权中心**路线：`条款与服务 → 售后服务 → 维权 / 索赔中心`。此入口独立于退款，不会自动跳转到退订页面。
- 维权一人一次；极小概率获得 1 亿绿宝石赔偿。赔偿记录保存在服务端，使用维权页的领取按钮分批获得实物绿宝石，不会覆盖背包现有物品。

## 安装（双端模式）

要在多人专用服务器中使用：

1. 服务器安装 **NeoForge 1.21.1**，将编译得到的 `cancel-subscription-2.2.0.jar` 放入服务器的 `mods` 文件夹。
2. **每名玩家也要安装同一版本的 JAR** 到自己的客户端 `mods` 文件夹。
3. 所有玩家使用对应的 Minecraft **1.21.1**、NeoForge **21.1.x**、Java **21** 进入服务器。
4. 按 O 打开界面，查看真实服务端同步的订阅状态和维权记录。

服务端负责扣费、虚构物品发放、索赔以及存档；客户端负责绘制 GUI 并请求操作。

## 构建

- 已提供 GitHub Actions：仓库上传源码后，进入 **Actions → Build NeoForge Mod → Run workflow**。它将使用 Gradle 8.10.2、Java 21 构建，并在构建后检查 JAR 内版本号、客户端 GUI/网络类和皇冠图标。
- 电脑本地安装 Gradle 8.10.2 后，进入项目根目录执行 `gradle build`。
- 编译产物预期位于 `build/libs/cancel-subscription-2.2.0.jar`。

## 发布前必须验证

> **本源码包尚未完成真实 Gradle 编译、专用服务器启动或多人在线联机测试。** 不得仅凭目录结构或 GitHub 成功标志宣布“服务端稳定可用”。

建议先按下列步骤手动测试：

1. **客户端单人游戏**：按 O、查看不同 GUI 缩放下文字是否清晰；检查条款、售后、维权之间的返回路径。
2. **维权**：点击维权申请，确认页面仍在维权中心，显示获赔结果/待领取绿宝石，而不是进入退订。
3. **退款**：连续完成十步挽留，确认退款后只在玩家在线时约每 100 tick 扣费 10 绿宝石，停止随机补货及其他事件收费。
4. **物品**：打开背包，确认自动补货只占空槽，使用虚构物品时不生成任何方块。
5. **专用服务器**：单独运行 NeoForge server，确认日志无 `ClassNotFoundException` / `NoClassDefFoundError`，两台客户端联机分别订阅，互不影响。
6. **持久化**：重进、跨维度以及死亡重生后确认状态、欠费、维权记录不丢失。

如果出现运行时崩溃，请保存服务器及客户端 `logs/latest.log` 以便进一步定位。
